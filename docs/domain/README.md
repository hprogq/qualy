# 综测领域入口

综测规则的权威正文是[综测领域设计](../assessment-design.md)。它包含冻结原则、完整业务对象、流程规则、尚未裁决的问题和后续裁决；修改综测业务前必须阅读相关章节，不能只读早期正文或历史方案。

## 先理解的主线

- Batch 决定一次测评的范围、阶段、事项和参与者快照。
- Entry 保存参评人的版本化填报；材料是受访问控制的独立对象。
- Review 处理审核中的不确定性、补件和上提；Appeal 是参评人对终局结论发起的另一条工作流。
- Recognition 是终局认定，Scoring 根据冻结配置计算结果；审核决定本身不携带分值。
- Publication 是不可变快照，正式发布后的更正不原地改写历史结果。
