# 历史文档

本目录保存仍有追溯价值、但不再指导当前开发的设计和迁移记录。阅读当前系统请从[文档入口](../README.md)开始；当前事实以代码、测试、ADR 和现行架构／领域文档为准。

## `designs`

这里保留已经完成、被替代或只服务某次实施的方案，包括：

- 装配、composition root、插件描述器和浏览器插件边界的施工设计；
- PrimeReact 到 Mantine、浏览器 RUM、OpenTelemetry 和开发监督者的实施计划；
- 认证、验证码、外部登录、行政认定、批次、阶段、事项和页面重构讨论；
- 旧 ORM、OCI、Web release 和沙箱落地方案。

这些材料保留“为什么这样做”和失败尝试，但其中的路径、阶段、版本和待办可能已经过期。与现行说明冲突时，不从归档恢复旧实现。

## `migrations`

这里保存已完成的大型技术迁移台账。Effect 迁移记录仍用于理解从 Cordis/oRPC 切换时的实测和取舍；Effect 的当前 API 必须按[源码政策](../agents/effect-source-policy.md)从仓库 `repos` 中与 catalog 同版本的源码核对。

原始聊天转录、逐会话教程、重复验收报告和整份第三方手册没有保留在当前树：Git 历史已经保存它们，现行 notes、ADR 和上游链接承担仍有用的结论。
