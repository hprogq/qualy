# ADR 0008:Claim 与 ScoreGroup 分离

- 状态:**已接受**(2026-08-08)
- 领域:综合素质测评(docs/assessment-design.md §7 ADR-5、§16)

## 背景

政策里有这样的条款:「优秀学生教官加 2 分;国旗班成员加 2 分;**兼具者共 3 分**」。
最直接的实现是在「优秀学生教官」题型里写 `if 也是国旗班 then 3 else 2`。

## 决定

**题目回答「这个事实成立吗、它单独值多少分」;ScoreGroup 回答「多个事实组合后计多少」。**

教官与国旗班是**两个题目**——分别举证、分别审核、分别申诉——挂进同一个 `cap = 3` 的组:

```text
只有教官     2
只有国旗班   2
二者都有     min(2 + 2, 3) = 3
```

**禁止在题型内部写 `if 国旗班 then …`**。组合规则(封顶、互斥、取最高)永远属于组,
不属于单个题型。这条对 M9 的 custom 计分器同样成立:沙箱内的函数**边界 = 单题内部**,
不得跨题读数据、不得在函数里做组合封顶。

## 后果

- 学生对「国旗班没算上」的申诉,指向的是国旗班那一条,不是一个混合判断。
- 组树自底向上计算,Breakdown 逐行保留截断过程(「教官/国旗班组合封顶 −1.00」),
  学生能看懂分是怎么来的——这是砍申诉量最有效的投资。
- 新增一条「兼具者共 N 分」的政策,是加一个组、调一个 cap,不是改代码。
