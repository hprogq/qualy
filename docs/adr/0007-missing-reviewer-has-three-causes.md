# ADR 0007:缺审核人分三种原因,绝不静默转移审批权

- 状态:**已接受**(2026-08-08)
- 领域:综合素质测评(docs/assessment-design.md §7 ADR-4、§14)
- 相关:[ADR 0006](0006-review-route-frozen-reviewers-live.md)

## 背景

审核链解析出空集合有三种完全不同的原因,把它们当成一件事处理,结果就是审批权被悄悄交给了
别人——而这在一个决定奖学金的系统里是最不能出的事。

## 决定

`resolve() -> []` 必须区分三种原因,各有各的出路:

- **结构性缺失**:锚点祖先链上根本不存在该 nodeType 节点(专业直属生没有班级)。这是**合法的
  组织形态** → 跳过该 stage、记录原因、normalTerminal 向后顺延。
- **职位空缺**:节点存在但无人持有该角色。这是**配置问题** → 条目/实例 `BLOCKED`,告警管理员
  补任命或转派。**不能偷偷找上一级替代**——那是静默转移审批权。
- **自审冲突**:解析结果含提交人本人 → 从候选中剔除;single/any 剔空则该 stage 对本条目跳过
  (记录 `self_review_conflict` 事件,normalTerminal 照第一种情形顺延);计票节点剔除后 quorum
  不可达 → 按第二种情形处理。**绝不允许自己审自己。**

兜底约束:**terminal stage 必须存在且解析非空**,否则拒绝提交并告警。不允许零人审核。

检查不只发生在提交时:条目**每次进入一个 stage**(提交、通过流转、上提)都重新解析该 stage
的审核人集合,为空立即 BLOCKED。运行期出现的空缺(角色被撤、组织变动)由五分钟档的监护巡检
发现并**双向自愈**——补任命后卡住的条目自动恢复,零任务迁移(见 assessment-design.md §14)。

## 后果

- 「专业直属生」这种编制特例不需要人工干预,系统自己认得出它是合法形态。
- 「班级存在但没有班长」会显式停下来要人,而不是让专业负责人在不知情的情况下代行班长职权。
- 有效链的快照里带着解释(哪一 stage 因何被跳过),写入第一个事件——事后能回答「为什么这条
  材料没经过班长」。
